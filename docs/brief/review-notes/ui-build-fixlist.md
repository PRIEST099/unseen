# UI build (Kiro IDE): fix list from Claude Code reviews

Issues found while verifying each task during the nonstop IDE run.

**Decision (owner, 2026-11-25):** these are **not** sent back to Kiro. Once Kiro has finished every `spirit-sight-ui` task (through 3.5), Claude Code applies all items below in **one** fix pass, on its own commits labelled `fix-pass (Claude Code)`, logged in `KIRO_SESSION_LOG.md` so the split between Kiro-built and Claude-fixed code stays transparent. Until then, items are only collected here; nothing is edited while the IDE run is going.

**Status (2026-11-25): all 28 items resolved** in the fix pass: commits 446d2a4 (items 14 and 22), 88e3717 (items 1 and 15, core) and 68f7ac3 (all other items, web). Item 25's step bar is recorded as a deviation in requirements.md 31.1, not built. Verified: web unit 392/392, e2e 84/84 including the self-audit, core 644/644 and 108/108.

Draw denser fog over The Fog nodes, scaled by contrast deficit. Make the moving band taller and denser (about 240 px) so it reads on video, and let the overlays glow on top of the fog.
