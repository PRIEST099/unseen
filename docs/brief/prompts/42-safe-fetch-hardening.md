Safe-fetch hardening follow-ups, from the product lead's verification of run 37. Each item gets a test that fails before the fix. Do not change any existing security assertion.

1. **Allowed authorities are dialled unpinned** (verified, low severity). `auditHtml` passes `audit-html.unseen.invalid:80` as an allowed authority. The proxy then dials it **by hostname** with OS resolution (no range check, no pinning). Case variants (`AUDIT-HTML.UNSEEN.INVALID:80`) and a trailing dot (`audit-html.unseen.invalid.`) reach that path too. `page.route` serves the synthetic origin over http(s), but **WebSockets bypass `page.route`**, so `ws://audit-html.unseen.invalid/` from user HTML reaches the proxy as CONNECT.
   - **Fix:** the proxy must **refuse** allowed/synthetic authorities (403 plus a `blockedRequests` entry), never dial them, because `route.fulfill` already serves them. Normalise case and trailing dots before any authority comparison.
   - **Tests:** CONNECT with case and trailing-dot variants gets 403; absolute-form gets 403; a canary resolver mapping that name to loopback gets zero hits.
2. **Dial robustness:** wrap every `dial()` call, including later Happy Eyeballs attempts, in try/catch, so a synchronous throw becomes a 502 plus a log entry and never an `uncaughtException`.
3. **Port parsing consistency:** the absolute-form parser dials port 0 (giving 502), while CONNECT rejects it with 400. Use one strict authority parser (port 1–65535) for both.
4. **Launch flags:** Chromium honours only one `--disable-features` switch, so **merge** the values instead of dropping one: `--disable-features=DnsOverHttps,WebRtcHideLocalIpsWithMdns` (plus any others already present). Add a test that asserts the exact single switch.
5. **Background traffic noise:** Chromium background requests (for example `www.google.com`) appear in `blockedRequests`, and they would show up in the UI. Add `--disable-background-networking`, `--disable-component-update`, `--disable-domain-reliability`, `--no-pings`, `--disable-sync` and `--metrics-recording-only` (check each against the current Chromium switch list; drop any that do not exist). Add a test: an audit of a simple page has no `blockedRequests` entries for hosts the page never referenced.
